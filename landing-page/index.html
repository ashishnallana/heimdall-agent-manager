Fleet

Every machine, one board.

Any model, on any machine — and every agent stays fully interactive.

  • Pick the model per agent, not per workspace. Claude Code, Codex and Qoder run side by side in the same chain.
  • Step into any worker mid-task. Open its terminal, type, steer it, hand it back — it keeps going.
  • Agents talk to each other across machines. A Claude agent on your laptop can message a Codex agent on the homelab and wait on its answer.
  • Every device dials out to one hub, so the whole fleet lands on a single board — no SSH, no VPN, no open ports.

Vault

Encrypted before it leaves the device.

Everything is encrypted with your key before it leaves your machine. The key stays with you.

  • Messages, tasks, memories and artifacts are sealed on your device before they sync.
  • Remote shells are encrypted too — the commands you type and the stream back. The bridge will not start a shell without your key.
  • File reads and writes are encrypted on the machine that holds them, before they ever cross the wire.
  • Your key is never shared to the hub. The hub only ever holds ciphertext it cannot read — not us, not anyone who walks off with the database.

Chain

Delegated. Built. Peer-reviewed.

Every task carries a named assignee and a named reviewer — and nothing lands on one agent’s word.

  • A coordinator splits the work into a chain, assigns each task, and wires up the dependencies between them.
  • Nothing completes until a reviewer votes LGTM, with evidence attached to the task.
  • Each task boots a fresh agent, so context rot never carries from one task into the next.
  • Fleet management fans the chain out across machines, so independent tasks run in parallel instead of queueing.

Memory

Fresh context, nothing forgotten.

Agents propose what they learned. You decide what sticks.

  • Every task starts from a clean window — then scoped memory is injected at boot.
  • Agents propose memories from their own work: facts, habits, skills and expertise, each with the evidence behind it.
  • You approve or reject every one. Nothing is remembered just because an agent felt strongly about it.
  • Scope decides reach — one agent, one project, one machine, or the whole fleet.
  • Learning crosses providers. A memory a Claude agent proposed on your laptop is injected into a Codex agent on another machine.

Work alongside

Your files and your shell, from anywhere.

The machines you work on at your desk, reachable from a browser or a phone — edit a file yourself, or drop into a real terminal and use the editor you already know.

  • Edit files in the browser — a file browser, tabs, and Vim keybindings if you want them, saving straight to the machine the project lives on.
  • Or open a real shell on any machine in the fleet — an interactive terminal, so vim, emacs or helix run exactly as they do when you are sitting in front of it.
  • A session is yours alone. Attaching to a terminal or sending it input is refused unless you own it — the hub checks the owner on both, every time.
  • Edits stay inside the project. Every write is resolved against the project root and refused if it lands outside it.
