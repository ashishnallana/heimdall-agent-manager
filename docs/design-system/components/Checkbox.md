# Checkbox

A boolean field submitted with a form: `<Checkbox checked onChange label size />`. 16px box, `radius 4px`.

| Prop | Values | Notes |
|---|---|---|
| `checked / onChange` | boolean | Controlled. |
| `label · children` | node | Optional second line in `nj-check__desc`. |
| `size` | `sm` · `md` |  |
| `disabled · invalid` | boolean |  |

Checked = `accent` fill with an `on-accent` check. **Use Toggle** for a setting that applies immediately.
