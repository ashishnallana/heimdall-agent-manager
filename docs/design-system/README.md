# Ninjy design system

The visual rules live in [`/DESIGN.md`](../../DESIGN.md); the values live in [`src/ui/tokens.css`](../../src/ui/tokens.css).

- [`components/`](components/) — guidelines and props for each `@ui` component the app uses (Button, Panel, Modal, …).
- [`migration.md`](migration.md) — old screen values and old token values mapped to the system, plus patterns to retire.
- [`tokens.json`](tokens.json) — the full token set (colours with usage notes, type styles, spacing, radii, shadows) in machine-readable form.
- Brand files: [`assets/brand/logos/`](../../assets/brand/logos/) and the 59 app icons as SVG in [`assets/brand/icons/`](../../assets/brand/icons/).
